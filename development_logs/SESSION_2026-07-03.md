### 2-1. `agent/routers/books.py` — 책 검색 API 병렬화 및 코드 정리

#### ✅ OpenLibrary 병렬 검색 추가

```python
# 변경 전: 네이버 API만 단독 호출
async with httpx.AsyncClient() as client:
    resp = await client.get("https://openapi.naver.com/v1/search/book.json", ...)
return resp.json()

# 변경 후: 네이버 + OpenLibrary 동시 호출
async with httpx.AsyncClient(timeout=8.0) as client:
    naver_task = client.get("https://openapi.naver.com/v1/search/book.json", ...)
    ol_task = client.get("https://openlibrary.org/search.json", ...)
    naver_resp, ol_resp = await asyncio.gather(naver_task, ol_task, return_exceptions=True)
```

- `asyncio.gather()`를 사용하여 두 API를 **동시에 비동기 호출**함으로써 응답 시간을 단축
- `return_exceptions=True`를 설정해 한쪽 API가 실패하더라도 다른 결과는 정상 반환되도록 처리
- `timeout=8.0`으로 타임아웃을 명시적으로 설정

#### ✅ OpenLibrary 결과 중복 제거 및 통합
