## Phase 4 추가 — 화자 분리 (Speaker Diarization)

### 백엔드

**`agent/state.py`** 업데이트

- `RecordingState`에 `transcript_segments`, `diarized_segments`, `user_speaker_label`, `labeled_transcript`, `user_contributions`, `voice_sample_path` 필드 추가

**`agent/nodes/transcribe_audio.py`** 업데이트

- `verbose_json` 응답에서 `transcript_segments` 추출 (dict/object 양쪽 접근 처리)

**`agent/nodes/diarize_speakers.py`** (신규)

- `Pipeline.from_pretrained("pyannote/speaker-diarization-3.1")` 싱글턴 로드
- `asyncio.to_thread()` 로 CPU-bound 작업 비동기 처리
- 반환: `diarized_segments: [{start, end, speaker}]`

**`agent/nodes/identify_user_speaker.py`** (신규)

- `pyannote/embedding` 모델로 각 화자 클립 임베딩 추출 (`Inference` 클래스, 싱글턴)
- pydub으로 화자별 오디오 클립 추출 (~10초), scipy 코사인 유사도, 임계값 0.5
- Whisper 세그먼트 ↔ pyannote 세그먼트 시간 overlap 정렬 → `labeled_transcript` 생성 ("나: ...", "화자 1: ...")
- 식별 실패 시 `user_speaker_label` 빈 문자열 유지, 레이블 없이 화자 번호만 표시

**`agent/nodes/analyze_discussion.py`** 업데이트

- `labeled_transcript` 우선 사용, 없으면 `transcript` 폴백
- 화자 식별 성공 시 Claude 프롬프트에 유저 발언 요약 포함

**`agent/graphs/recording_analysis.py`** 업데이트 — 5노드 그래프

```
START
  → transcribe_audio
  → diarize_speakers
  → identify_user_speaker
  → analyze_discussion
  → generate_recording_questions
  → END
```

**`agent/routers/users.py`** 업데이트

- `POST /api/users/{user_id}/voice-sample` 추가
- `uploads/voice_samples/user_{id}.{ext}` 로컬 저장, DB `voice_sample` 컬럼 업데이트

**`agent/routers/recordings.py`** 업데이트

- 업로드 시 `users.voice_sample` 경로 조회 → 그래프 초기 상태에 `voice_sample_path` 주입
- 응답에 `labeled_transcript`, `user_contributions` 포함

**`agent/db.py`** 업데이트

- `users` 테이블 `voice_sample VARCHAR(500)` 컬럼 추가 (`ALTER TABLE IF NOT EXISTS`)

**`agent/Dockerfile`** 업데이트

- 시스템 패키지: `libsndfile1`, `ffmpeg` 추가
- torch/torchaudio CPU 전용 먼저 설치 (`--index-url https://download.pytorch.org/whl/cpu`, ~4GB 절감)
- `/app/uploads/voice_samples` 디렉토리 사전 생성

**`agent/requirements.txt`** 업데이트

- `pyannote.audio>=3.1.0`, `scipy>=1.11.0`, `soundfile>=0.12.0`, `pydub>=0.25.0` 추가

**`backend/.env.example`** 업데이트

- `HUGGINGFACE_TOKEN=` 추가 (pyannote 모델 약관 동의 필요)
