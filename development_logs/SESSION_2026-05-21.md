## 1. 개요 (Summary)

이 날은 독서 커뮤니티 앱의 UX 및 기능 완성도를 높이기 위한 전반적인 개선 작업이 진행되었습니다. 크게 네 가지 방향으로 개발이 이루어졌으며, **프론트엔드의 시각적 정렬 개선**, **커뮤니티 좋아요 반응성 향상**, **댓글 구조의 대댓글 체인 지원**, 그리고 **읽은 책에 대한 감상평 기능 신규 추가**가 핵심입니다. 백엔드에서는 DB 스키마 변경(컬럼 추가, 신규 테이블 생성)과 함께 RESTful API 엔드포인트가 다수 추가되었고, 프론트엔드는 이를 반영하는 UI 컴포넌트 및 상태 관리 로직이 대폭 확장되었습니다.

## 2. 주요 변경 사항 및 구현 세부 정보

### 📁 `agent/db.py` — DB 스키마 확장 및 시드 데이터 구축

#### 2-1. `comments` 테이블 — 대댓글 지원 컬럼 추가
```sql
ALTER TABLE comments ADD COLUMN IF NOT EXISTS parent_comment_id
    INTEGER REFERENCES comments(id) ON DELETE SET NULL
```
- 기존 댓글 테이블에 `parent_comment_id` 컬럼을 추가하여 **flat 구조 기반의 대댓글(답글) 체인**을 지원하도록 변경.
- 자기 참조 외래키(self-referencing FK)로 설계하였으며, 부모 댓글 삭제 시 자식 댓글의 FK는 `NULL`로 처리(`ON DELETE SET NULL`).

#### 2-2. `read_books` 테이블 — 감상평 및 공개 여부 컬럼 추가
```sql
ALTER TABLE read_books ADD COLUMN IF NOT EXISTS impression TEXT DEFAULT ''
ALTER TABLE read_books ADD COLUMN IF NOT EXISTS is_public BOOLEAN DEFAULT TRUE
```
- 읽은 책 기록에 **사용자 감상평(`impression`)** 및 **공개/비공개 설정(`is_public`)** 기능을 위한 컬럼을 추가.
- 기본값으로 감상평은 빈 문자열, 공개 여부는 `TRUE`로 설정하여 하위 호환성 유지.

#### 2-3. `club_reviews` 테이블 — 신규 생성
```sql
CREATE TABLE IF NOT EXISTS club_reviews (
    id SERIAL PRIMARY KEY,
    club_id INTEGER REFERENCES clubs(id) ON DELETE CASCADE,
    user_id INTEGER REFERENCES users(id) ON DELETE SET NULL,
    rating INTEGER NOT NULL CHECK (rating >= 1 AND rating <= 5),
    review_text TEXT DEFAULT '',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(club_id, user_id)
)
```
- 독서 모임(클럽)에 대한 **평점 및 리뷰 기능**을 위한 신규 테이블 생성.
- `UNIQUE(club_id, user_id)` 제약으로 동일 사용자가 같은 모임에 리뷰를 중복 등록하는 것을 방지.
- 평점은 1~5 사이의 정수만 허용하는 `CHECK` 제약 조건 적용.
