### 2-1. DiveRoomModal UX 개선 (`frontend/src/components/modals/DiveRoomModal.jsx`)

#### ✅ 실시간 카운트다운

- 기존 30초 주기 tick을 **1초 주기**로 변경
- `computePhaseInfo(room)` 함수 신규 작성 — `{ phase, remaining }` 반환 (기존 `computePhase` 대체)
- `fmtRemaining(ms)` 함수 — ms → "X분 YY초" / "X시간 Y분" 포맷 변환
- 페이즈 배지에 남은 시간 실시간 표시 ("독서 중 · 8분 32초")

```javascript
function computePhaseInfo(room) {
  const now = Date.now();
  const start = new Date(room.scheduled_at).getTime();
  const readEnd = start + (room.reading_minutes || 0) * 60000;
  const discEnd = readEnd + (room.discussion_minutes || 0) * 60000;
  if (now < start)    return { phase: 'waiting',    remaining: start - now };
  if (now < readEnd)  return { phase: 'reading',    remaining: readEnd - now };
  if (now < discEnd)  return { phase: 'discussion', remaining: discEnd - now };
  return { phase: 'overtime', remaining: 0 };
}
```

#### ✅ 페이즈 전환 토스트

- `prevPhaseRef` + `useEffect`로 phase 변화 감지 → 4초 후 자동 소멸
- reading / discussion / overtime 각각 다른 색상·텍스트 표시

#### ✅ 독서 종료 5분 전 경고 배너

- `showReadingWarning = phase === 'reading' && remaining < 5분`일 때 헤더 하단에 슬라이드인
- `AnimatePresence` + `height: 0 → 'auto'` 애니메이션
- 남은 시간 비율로 줄어드는 진행률 바 (`linear-gradient(90deg, #ef4444, #f97316)`)

#### ✅ 모달 최소화

- `minimized` state 추가, 헤더에 `<Minimize2>` 버튼
- `minimized === true`이면 backdrop 없이 early return → 우하단 고정 플로팅 pill 렌더
  - 방 썸네일 · 페이즈 배지 · 방 제목 · 카운트다운 · 복원 버튼
  - `position: fixed, bottom: 1.5rem, right: 1.5rem, zIndex: 1000`

```sql
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(blocker_id, blocked_id)
);
```

### 2-4. Dive 참여 이력 API 수정 (`agent/routers/dive.py`)

- `get_hosted_rooms`: `HAVING COUNT(DISTINCT p.id) > 1` 제거 → 본인만 있는 방도 이력에 표시
- `GET /rooms/joined` 신규 추가 — 참여자로 들어간 모임 목록

```python
@router.get("/rooms/joined")
async def get_joined_rooms(conn=Depends(get_db), user_id: int = Depends(get_current_user_id)):
    rows = await conn.fetch("""
        SELECT r.*, COUNT(DISTINCT p.id)::int AS participant_count
        FROM dive_rooms r
        JOIN dive_participants dp ON dp.room_id = r.id AND dp.user_id = $1
        LEFT JOIN dive_participants p ON p.room_id = r.id
        WHERE r.host_id != $1
        GROUP BY r.id
        ORDER BY r.scheduled_at DESC
    """, user_id)
    return [dict(r) for r in rows]
```
